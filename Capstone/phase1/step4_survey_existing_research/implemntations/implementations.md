# Public Implementations

| Resource                                                         | Repo URL                                                                 | Install & Quick Start                                                                                          |
|------------------------------------------------------------------|-------------------------------------------------------------------------|----------------------------------------------------------------------------------------------------------------|
| **CLIP** (Radford et al., 2021)                                  | https://github.com/openai/CLIP                                           | ```bash<br>pip install -r requirements.txt<br>python demo.py \  <br>  --image_path img.jpg \  <br>  --text "a cat"``` |
| **X-modaler** (Ye Li et al., 2021)                                | https://github.com/YehLi/xmodaler                                         | ```bash<br>pip install -r requirements.txt<br>python train.py --task retrieval --dataset coco```              |
| **HAT** (Yi Bin et al., 2023)                                     | https://github.com/LuminosityX/HAT                                        | ```bash<br>conda env create -f environment.yml<br>python run_retrieval.py --config configs/coco.yaml```         |
| **DCLIP** (Csizmadia et al., 2025)                                | https://anonymous.4open.science/r/DCLIP-B772/README.md                    | Follow link for code & checkpoints; likely ```pip install -r requirements.txt``` then run provided scripts      |
| **Reverse Stable Diffusion** (Croitoru et al., 2023)             | https://github.com/CroitoruAlin/Reverse-Stable-Diffusion                 | ```bash<br>pip install -r requirements.txt<br>python invert.py --image_path sd_output.png```                   |
| **Image-to-Prompts** (Jackson Chen)                              | https://github.com/jacksonchen1998/Image-to-Prompts?tab=readme-ov-file    | ```bash<br>pip install -r requirements.txt<br>python cli.py --input img.png --output prompt.txt```             |
| **Stable-Diffusion-Image-to-Prompts** (Mingyuan Ren)              | https://github.com/MingyuanRen/Stable-Diffusion-Image-to-Prompts?utm…     | ```bash<br>pip install -r requirements.txt<br>python infer_prompt.py --img_path img.png```                     |
